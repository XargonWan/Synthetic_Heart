Development: `pnpm dev` runs Vite with a dev server serving under base `/stage/` and proxies backend requests. Build: `pnpm build` runs `vue-tsc --noEmit` then `vite build`. Preview: `pnpm preview`. Typecheck: `pnpm typecheck`. E2E verification scripts under `scripts/` (e.g. `m2-action-check.mjs`, `auth-ux-ui-check.mjs`, `tts-chunking-check.mjs`) launch a Chromium browser, navigate to `/stage/`, and exercise features against a running backend.
