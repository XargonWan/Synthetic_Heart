Built with Sphinx using the ReadTheDocs theme. `conf.py` is the central configuration: it enables autodoc, Napoleon, viewcode, graphviz, and myst-parser to support both `.rst` and `.md` source files. A custom `setup()` hook connects `_collect_plugin_guides` to the `config-inited` event, which scans the `plugins/` directory for `guide.md` files (three layouts supported: folder plugins, grouped sub-plugins, and single-file `*.guide.md`) and copies them into `docs/plugins/generated/`, also copying shared assets like `GRILLO.png`. The top-level `index.rst` defines two toctrees — a User guide and a Developer guide — that pull in all rst/md pages plus the generated plugin index. Static assets live under `_static/` and `res/` (screenshots, logos). Build output goes to `docs/_build/html` via `sphinx-build -b html docs docs/_build/html`.
