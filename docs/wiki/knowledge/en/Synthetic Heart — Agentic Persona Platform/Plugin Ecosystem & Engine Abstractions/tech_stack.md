Pure Python with `abc.ABC` + `@abstractmethod` for engine interfaces, `dataclasses` for result/event models, `asyncio` for streaming/live sessions and background schedulers, and a plugin registry pattern driven by `core.core_initializer.register_plugin`. External integrations include Vosk (STT), Gemini Live (streaming), AzuraCast (radio), Minecraft via a Node.js bridge (`minecraft_bridge.js`), and Tavily/SearXNG/DuckDuckGo for web search.
