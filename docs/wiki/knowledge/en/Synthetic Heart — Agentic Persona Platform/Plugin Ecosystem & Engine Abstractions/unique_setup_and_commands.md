Each engine subclass must set `ENGINE_CLASS = MyEngine` and call its corresponding `register_*_engine(...)` at module import time so the core can discover it. Feature plugins call `register_plugin("<id>", self)` inside `__init__`. Config variables are exposed to the WebUI via `core.variables_engine.register_exposed_var(...)` calls at module level. No build step is required — plugins are loaded dynamically by the core initializer.
