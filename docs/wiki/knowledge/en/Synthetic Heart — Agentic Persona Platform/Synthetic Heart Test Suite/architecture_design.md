Tests are organized by feature area with one `test_*.py` file per concern at the root (unit tests), plus four sub-packages: `e2e/` for Playwright-style browser tests (`index.spec.js`, `webui.spec.js`), `integration/` for cross-process integration tests, `interface/` for platform interface contracts, and `plugins/` for plugin-specific behavior. Shared fixtures live in `conftest.py` (autouse singleton reset, temp backups dir, blocking live ai_diary DB access). Optional third-party dependencies are stubbed via `__init__.py` using a `_ensure_module` helper so imports succeed without those packages installed. A separate `stress_test_engines.py` script drives concurrent HTTP calls against a local Ollama endpoint, and `synth_api_test.py` is a standalone API smoke client. The README documents the pytest + uv workflow and CI JUnit output expectations.
