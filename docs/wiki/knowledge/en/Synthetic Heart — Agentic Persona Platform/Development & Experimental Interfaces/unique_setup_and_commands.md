Each interface requires specific environment variables to activate: `REDDIT_CLIENT_ID` + `REDDIT_CLIENT_SECRET` (+ optional `REDDIT_USERNAME`, `REDDIT_PASSWORD`, `TOKEN`, `REDDIT_USER_AGENT`) for Reddit; `API_ID`, `API_HASH`, `SESSION`, and `TRAINER_IDS` for the Telegram userbot; `X_USERNAME` for X/Twitter. The `telethon_userbot.py` can be run standalone via `python telethon_userbot.py` which boots its own event loop and calls `core_initializer.initialize_all`. All interfaces are only loaded when the WebUI's `dev_components` flag is set to True.
