Each file defines a self-contained interface class that registers itself with the core via `core.core_initializer.register_interface` (and sometimes also `register_interface` from `core.transport_layer`) at module import time. The package follows two patterns: (1) legacy-style interfaces like `RedditInterface`, `XInterface`, and the Telethon client object expose static `get_interface_id`, `get_supported_actions`, `get_prompt_instructions`, and `send_message`/`execute_action` methods so the action dispatcher can invoke them; (2) the `BaseInterface`-derived pattern shown by `ExampleDevInterface` which subclasses `core.interface_adapters.BaseInterface` and auto-registers through `register_interface(INTERFACE_NAME, instance())`. All interfaces gate external dependencies behind try/except blocks (`asyncpraw`, `telethon`, `snscrape`) and skip initialization when required environment variables are missing, ensuring the rest of the system stays functional without optional integrations. The `__init__.py` documents that these modules are conditionally loaded only when `dev_components_enabled=True`, with the flag reset on every restart for safety.
