Plugins require environment variables for external services: `REDDIT_CLIENT_ID`, `REDDIT_CLIENT_SECRET`, `REDDIT_USERNAME`, `REDDIT_PASSWORD`, `REDDIT_USER_AGENT` for Reddit; `ELEVENLABS_EMAIL`, `ELEVENLABS_PASSWORD` for ElevenLabs login; `synth_SELENIUM_HEADLESS=1` to run Chromium headless. A Chromium binary must be available on PATH (`chromium`, `chromium-browser`, or `/usr/bin/chromium`). The `dev_components` WebUI flag must be enabled for these plugins to load, and it resets to False on every restart.
