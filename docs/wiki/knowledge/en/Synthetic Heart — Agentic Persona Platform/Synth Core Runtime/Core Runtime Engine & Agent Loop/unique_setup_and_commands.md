Startup is driven by `CoreInitializer.initialize_all(notify_fn)`, which must be called once during process boot. Agentic runtime configuration keys (`AGENT_ENABLED`, `AGENT_MAX_ITERATIONS`, `DRONE_*`) are eagerly registered before `load_all_from_db()` so their DB values are not lost. Interrupted agent tasks are reconciled on startup by marking `running`/`paused` rows as `failed` with `stop_reason=interrupted_by_restart`.
