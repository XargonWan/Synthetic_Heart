Connectors must define a module-level `CONNECTOR_CLASS` and call `register_vessel_connector(name, module_path, capabilities, label)` at import time. End-of-session compaction prefers a handler registered via `VesselSessionManager.set_compaction_handler()` (used by `plugins/rift_vessel/vessel_compactor`); if none is registered the legacy inline path falls back to `compact_session`. The session cooldown is driven by `close_expired_sessions(cooldown_sec)` called periodically by the interface scheduler.
