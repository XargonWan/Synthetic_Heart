Connectors must define a module-level `CONNECTOR_CLASS` and call `register_vessel_connector(name, module_path, capabilities, label)` at import time. End-of-session compaction prefers a handler registered via `VesselSessionManager.set_compaction_handler()` (used by `plugins/rift_vessel/vessel_compactor`); if none is registered the legacy inline path falls back to `compact_session`. The session cooldown is driven by `close_expired_sessions(cooldown_sec)` called periodically by the interface scheduler. Enable the generic `goals` plugin for self-authored objectives; Minecraft's connector pins calls to the vessel/Minecraft scope tuple. `VESSEL_ACTION_WHITELIST` controls optional non-embodiment actions retained in the vessel prompt catalog; vessel and active-world actions are always retained structurally.
