Core runtime for SyntH's Rift Vessel embodiment: connector registry, session lifecycle with buffered lived experience, two-speed autonomy (will/action beats and motor tick), self-authored goals and quests, end-of-session diary compaction, and structural vessel-turn detection.

The embodiment stack also includes plugin-owned behavior around this core: `plugins/rift_vessel/vessel_plugin.py` exposes connection-driven world actions, `plugins/rift_vessel/vessel_whitelist.py` keeps vessel prompts focused on embodiment actions, and `plugins/rift_vessel/vessel_compactor/` owns asynchronous operational recap generation. The generic `plugins/goals/goals.py` plugin provides scope-aware free-text goals for vessel and non-vessel callers; Minecraft-specific compatibility and progression logic lives under `plugins/rift_vessel/minecraft/`.
