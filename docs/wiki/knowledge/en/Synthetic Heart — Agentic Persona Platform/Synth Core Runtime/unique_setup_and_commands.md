Startup is driven by `CoreInitializer.initialize_all()` which must be called once at process start; it internally calls `_initialize_registries`, `_load_cortex_engine`, `_load_plugins`, `_ensure_core_actions`, `_discover_interfaces`, `_initialize_interface_instances`, and `_start_interfaces` in a fixed order, and performs a one-time recovery of interrupted agent tasks left running by a previous process.
