Flat collection of independent helper modules under `core/`, each exposing pure functions or small classes with no shared base class. Dependencies flow inward toward a few core subsystems: `logging_utils` is the central logging facade (with its own `setup_logging()` singleton) and is imported by nearly every other module; `config_manager.config_registry` is used to register runtime-configurable variables (e.g. `TZ`, `LOGGING_LEVEL`) so values can change without restart; `abstract_context.py` defines dataclass-based `AbstractUser`/`AbstractMessage`/`AbstractChat` plus an `AbstractContext` that delegates trainer checks through `interfaces_registry`. Modules avoid circular imports by lazy-importing heavy dependencies inside functions (e.g. `log_archive`, `chat_history_cache`, `session_meta`). There is no package `__init__.py` — each file is self-contained and imported directly by callers.
