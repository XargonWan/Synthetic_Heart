Python stdlib (`logging`, `zoneinfo.ZoneInfo`, `datetime`, `json`, `re`, `dataclasses`), `icalendar` for iCalendar event serialization, `python-dotenv` for `.env` loading, and the project's own `core.config_manager` config registry for runtime configuration. Logging uses a custom `TimeZoneFormatter` and a `TimestampedRotatingFileHandler` that integrates with `core.log_archive` for daily rotation, gzip compression, and retention enforcement.
