Logging auto-initializes on import: it loads `.env` from both CWD and `/app/.env`, creates the `logs/` directory, and sets up `synth.log` plus an additive `synth_errors.log`. The `LOG_DIR`, `LOGGING_LEVEL`, `LOGGING_LOGCHAT_LEVEL`, and `LOG_RETENTION_DAYS` environment variables control behavior at startup. Timezone defaults come from the `TZ` config variable registered in `time_zone_utils.py`.
