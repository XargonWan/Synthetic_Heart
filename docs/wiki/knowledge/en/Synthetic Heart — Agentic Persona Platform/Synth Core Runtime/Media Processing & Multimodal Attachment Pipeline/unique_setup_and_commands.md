Requires ffmpeg and ffprobe on PATH for audio extraction, video frame decomposition, and YouTube audio downloads. yt-dlp must be installed for YouTube subtitle/audio fetching. Temporary files are written under `tmp/recon_media/` and must be cleaned up by callers via `YouTubeFetchResult.cleanup()`. The `VOX_OUTPUT_DIR` config value controls where generated TTS audio is served from and determines URL derivation.
