Async MySQL via `aiomysql` (optional, stubbed when missing) and async PostgreSQL via `asyncpg` (optional, checked through `postgres_driver_available()`). External dump tools `pg_dump` and `mysqldump` are invoked as subprocesses for backups. Connection pooling uses `asyncpg.create_pool` for Postgres and `aiomysql.create_pool` for MariaDB, scoped per event loop to avoid cross-loop reuse errors.
