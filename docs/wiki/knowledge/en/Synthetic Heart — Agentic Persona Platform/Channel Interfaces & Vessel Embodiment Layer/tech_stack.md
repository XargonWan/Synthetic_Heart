Python async interfaces over discord.py (with optional `discord.ext.voice_recv` and DAVE E2EE via `davey`), python-telegram-bot, matrix-nio, and aiohttp; the Minecraft bridge is a Node.js/Mineflayer subprocess managed via `asyncio.create_subprocess_exec` with health probing on `/health`. Outbound Telegram sends use exponential backoff, per-chat cooldown queues, and a dedup window configurable via `OUTGOING_DEDUPE_WINDOW`.
