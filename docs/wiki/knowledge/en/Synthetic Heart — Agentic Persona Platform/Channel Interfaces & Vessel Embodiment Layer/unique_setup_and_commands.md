Each channel interface requires platform-specific dependencies (e.g. `discord.py` with voice support, `python-telegram-bot`, `matrix-nio`). The Minecraft bridge requires Node.js and npm; `BridgeProvisioner.install()` runs `npm install --no-audit --no-fund mineflayer mineflayer-pathfinder minecraft-data mineflayer-collectblock mineflayer-auto-eat` inside `plugins/rift_vessel/minecraft/mineflayer/`. Bridge startup is gated by `PLUGIN_ENABLED__minecraft_vessel` and can be autostarted via `MINECRAFT_BRIDGE_RUN_AT_START=true`.
