The repository is a Python monorepo whose entry point `main.py` boots the event loop, loads `.env` defaults, initializes the database (SQLite or PostgreSQL), then delegates to `core.core_initializer` which discovers and registers all components via a shared plugin protocol. Children are organized by concern: `core_runtime` provides the message pipeline and SOUL persistence; `engines` supplies hot-swappable LLM/STT/TTS backends; `interfaces` and `interface_dev` expose Discord/Telegram/Matrix/WebUI channels plus experimental adapters; `plugins` and `plugins_dev` add actions and background tasks; `mcp_servers` exposes observability tools via Model Context Protocol; `frontend` is a standalone Vue 3/Three.js avatar UI; `documentation` is a Sphinx site; `tests` covers unit/integration/e2e cases. Cross-child wiring is enforced through registries (`core.cortex_registry`, `INTERFACE_REGISTRY`) and configuration files under `providers/*.json` and `config/mcporter.json`. Docker (`Dockerfile`, `docker-compose.yml`) and `webtop/` provide containerized runtime with s6-services orchestrating Synth and websockify processes.
