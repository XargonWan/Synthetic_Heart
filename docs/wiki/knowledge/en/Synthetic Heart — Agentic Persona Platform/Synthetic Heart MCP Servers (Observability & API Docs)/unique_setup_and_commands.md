Each Python server is run directly with `uv run python mcp_servers/<server>.py` and registered in `.mcp.json`. The TypeScript server requires `npm install` then `npm run build` (runs `tsc && cp -r src/data dist/`) before `npm start` (or `node dist/index.js`). All servers read configuration from the repository-root `.env` file, which must contain keys like `DB_*`, `SOURCE_DB_*`, `SOUL_POSTGRES_DSN`, `LANGFUSE_HOST`, `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY` depending on the server.
