Un sistema modulare di persona AI — plugin estensibili, motori LLM intercambiabili, animazioni VRM e interfacce multiple.

Get started Documentazione

Quick start

  1. Clona il repo: git clone https://github.com/XargonWan/Synthetic_Heart.git
  2. Sincronizza dipendenze: uv sync
  3. Avvia dev (locale): ./synth.sh o docker compose -f docker-compose-dev.yml --env-file .env-dev up -d --build

Modulare

Plugin e interfacce scambiabili: aggiungi nuove azioni senza toccare il core.

LLM-friendly

Supporto per motori multipli — hot-swappable e testabili.

Animazioni

Gestione avanzata di animazioni VRM per avatar reattivi.

Estendibile

Architettura progettata per integrazioni e agenti background.
